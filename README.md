## 🛠️ Як працювати з репозиторієм у Visual Studio Code

1. Склонувати репозиторій: `Get Started` → `Clone Git Repository...` → обрати цей репозиторій.
2. Відкрити папку репозиторію у VS Code та вносити зміни у файли.
3. Увімкнути автозбереження: `Manage` → `Settings` → `Auto Save`.
4. Перейти на вкладку **Source Control**, натиснути **+**, щоб додати змінені файли.
5. Написати коротке повідомлення та натиснути **Commit**.
6. Натиснути **Sync Changes**, щоб відправити зміни на GitHub.

Або через термінал:

```bash
git add .
git commit -m "Опис змін"
git push
```
