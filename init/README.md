### 2. Експерименти з Markdown

#### 2.1 Форматування тексту

| Що пишемо | Результат |
|---|---|
| `**жирний**` | **жирний** |
| `*курсив*` | *курсив* |
| `~~закреслений~~` | ~~закреслений~~ |
| `` `код` `` | `код` |

#### 2.2 Списки

Нумерований:
1. Перший пункт
2. Другий пункт
   1. Вкладений пункт

Маркований:
- Яблуко 🍎
- Банан 🍌
  - Вкладений елемент

#### 2.3 Цитата

> Програмування — це не про те, що ти знаєш, а про те, що ти можеш з'ясувати.

#### 2.4 Блок коду

```python
class Student:
    def __init__(self, name, group):
        self.name = name
        self.group = group

    def hello(self):
        print(f"Привіт! Я {self.name} з групи {self.group}")
```
